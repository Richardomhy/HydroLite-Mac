# Historical Flood Validation User Guide

Prepare event, rainfall, flow, stage, station, and optional reservoir observations with the upload templates. Run readiness, event detection, QC, mapping, and chronological splitting; review low-confidence mappings. Run full-hydrograph hindcasts and water-balance checks before calibration. Calibrate only on calibration events, then report validation, test, and worst-event performance. Assimilation outputs must distinguish open-loop, analysis, and forecast-from-analysis. Synthetic demo metrics are software checks, not real validation.
