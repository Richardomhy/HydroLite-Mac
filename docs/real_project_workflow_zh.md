# 真实项目工作流

1. 创建 `workspaces/<project_id>/`。
2. 根据模型需求上传本地必需数据。
3. 校验格式、字段、单位、时间、CRS 和空间覆盖。
4. 确认低置信度映射；修复副本进入 `standardized/`。
5. 对可获取数据生成 GEE、Earthdata、CDS 或 STAC 计划。
6. 审查许可、范围、预计大小和登录要求后再决定是否下载。
7. 运行需求矩阵和输入构建器。
8. 从数据中心进入项目向导生成项目和 case。
9. 运行 validate，再启动模型和报告导出。

云端适合小文件预览、映射和报告；本地版适合 QGIS、HEC-HMS、SWMM 和大型空间数据。当前数据中心为 `partial`。
