# Production Operations User Guide

1. Create a workspace in Data Center and pass quality gates.
2. Register it in Project Center and review readiness.
3. Select a recipe, inspect the plan, then create and start a run.
4. Use Task Center for logs, cancellation, and explicit retry.
5. Required failures block downstream work; optional failures preserve completed artifacts.
6. Preview, validate, download, or bundle outputs in Artifact Center.
7. Inspect mode, backends, disk, and database in System Center.
8. Export project/run snapshots for reproducibility.

Cloud mode supports lightweight operations only.
