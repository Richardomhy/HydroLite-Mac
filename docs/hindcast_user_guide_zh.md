# 历史洪水验证用户指南

1. 按 `templates/data_upload/` 准备事件、降雨、流量、水位、测站和可选水库观测。
2. 运行 readiness、事件检测、QC、映射和划分，并人工核对低置信度项。
3. 运行多事件回放，先检查每场全过程线和水量平衡。
4. 只在率定集执行参数搜索，再检查验证集、测试集和最差事件。
5. 可选运行 Nudging/EnKF 和 1/3/6/12 小时验证；报告中区分 analysis 与 forecast。
6. 从“历史洪水验证”页面下载中英文报告与安全 Bundle。

演示数据全部标记 `synthetic_demo: true`，不得作为真实项目结论。
