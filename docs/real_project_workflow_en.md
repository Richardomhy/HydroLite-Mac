# Real Project Workflow

Create a workspace, upload required local data, validate format/schema/units/time/CRS/coverage, confirm uncertain mappings, plan optional acquisition, review license/size, build standardized inputs, create and validate a project, run the workflow, and export quality/lineage/readiness reports.

Cloud mode is for small-file inspection and demonstrations. Local mode supports optional QGIS, HEC-HMS, SWMM and larger spatial workflows. The data center remains `partial`.
