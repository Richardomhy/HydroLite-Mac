# 来源许可与 clean-room 边界

来源可被阅读或检索，不代表其代码、文字、图表、数据集资产或模型实现可以复制。许可评估分别记录代码、文本、图表、数据、衍生作品和商业使用的边界。

对缺少许可证的第三方仓库，HydroLite 固定采用 `license_file_missing` 与 `clean_room_only`：不复制源码、SKILL/README 文案、目录资产；不作为运行时依赖、子模块、构建下载或桌面包内容。仅可独立借鉴通用产品能力，例如离线目录、检索、比较、官方引用与完整性检查。

执行 `python -m hydrolite research licenses` 导出审计结果。
